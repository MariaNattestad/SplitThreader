# SplitThreader

SplitThreader is an interactive web application for analysis of rearrangements and copy number in a cancer genome.

## SplitThreader has moved into Ribbon! https://genomeribbon.com

This is a massive update to SplitThreader, which makes it much faster to use and integrated with the powerful Ribbon visualizations for digging deeper into those large SVs of interest.

SplitThreader no longer has a back-end and therefore doesn't require any data uploads or processing time. Read more about the move at 
https://github.com/MariaNattestad/Ribbon/blob/main/docs/release_notes_v2.md

Please use the Ribbon GitHub repo from now on: https://github.com/MariaNattestad/Ribbon
